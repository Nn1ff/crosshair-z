# Crosshair Z 2.0.1

Fixes icons in the settings window.

## Changes

- Filled icons were invisible in the native (WebView2) settings window: the Settings
  gear in the sidebar was blank and saved crosshairs showed an empty bookmark instead of
  a filled one. The dot, ring and reticle icons were affected the same way.

## Upgrade

Download `Crosshair-Z.exe` from the release, or use the in-app update. Settings and
crosshairs carry over unchanged. The portable exe is unsigned and Windows may show
SmartScreen.

## Verified release package

- Rust unit tests, golden sprite comparison and JavaScript tests passed.
- All eight live smoke checks passed (rendering, renderer cleanup, single instance,
  disk-cache restart, no error logs).
- Gear and filled bookmark icons checked on screenshots of the actual native settings UI.
