## Crosshair Z 2.0.5

DOM Fortnite imports now preserve fractional line lengths and render their glow with SVG Gaussian filters. Designer zoom, actual-size preview and native overlay use the same rendered pixels, so toggling the crosshair preserves its size and appearance.

SVG rendering covers imported four-arm rectangle models with supported dot shapes. Other layer types keep the existing Canvas renderer. Re-import designs imported by an older version to recover rounded values.

### Update integrity

- Require a valid SHA-256 digest from GitHub release metadata and verify downloaded bytes before installing an update.
- Restrict update URLs to Crosshair Z's repository, matching version and executable name.
- Explain Windows antivirus errors 225/226 with the Protection history location; no exclusions or security bypasses are offered.

Validation: 109 Rust unit tests and 34 JavaScript tests pass. Tests cover altered downloads of the same size, absent/malformed digests, wrong repositories/versions and antivirus errors. SVG references were checked at 1×, 2×, 8× and 16×. Isolated native checks confirm identical preview/overlay pixels and unchanged sprites after four toggles.

### Microsoft Defender review pending

The original 2.0.3 executable and this exact 2.0.5 build have been submitted to Microsoft following a reported `Trojan:Win32/Bearfoos.A!ml` detection on 2.0.3. The review is pending. This release is unsigned and does not yet have a confirmed Microsoft clearance; the updater changes alone do not establish that the detection is resolved.
