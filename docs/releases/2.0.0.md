# Crosshair Z 2.0.0

Crosshair Z now uses Rust and a native Windows overlay. The existing designer and
crosshair renderer use WebView2 only when needed. Closing settings releases the browser
processes, leaving the overlay running.

## Changes

- Native Win32 overlay, tray, global hotkeys and mouse handling.
- Shared designer and renderer, profiles, share codes and Crosshair X import.
- Disk-cached crosshair sprites for fast restarts without starting WebView2.
- Updater, autostart and instance handover compatible with the portable asset name.
- Fixed animation freezing during relayout, stale settings-close timers and premature
  render timeouts. Isolated test data now uses separate instance endpoints.
- Refreshed repository banner, screenshots, build guide and dependency documentation.

## Requirements and upgrade

Download `Crosshair-Z.exe` from the release. Microsoft Edge WebView2 Runtime is required
for settings and generating uncached crosshairs; the Edge browser does not need to be open.
The portable exe is unsigned and Windows may show SmartScreen.

Version 2.0 reads the existing `%APPDATA%\Crosshair Z\config.json`. Back it up before
upgrading. Re-select your monitor if you used a secondary display, because native monitor
IDs differ from Electron IDs. The 1.8.x updater can offer this stable release.

- 105 Rust unit tests and 41 JavaScript tests passed.
- Golden comparison of 54 designs at three firing levels passed (162 references).
- Clippy with warnings denied and `git diff --check` passed.
- All eight live smoke checks passed, including sprite rendering, renderer cleanup,

- Measured idle private working set: 5.3 MB with settings closed.
- Portable exe: 3.85 MB. Open settings also consume memory in WebView2 child processes.
- Four screenshots were captured from the actual native settings UI and visually checked.

Measurements cover the local Windows desktop. Game compatibility, every input combination,
mixed-DPI setups and installed 1.8.7 handover were not exhaustively tested.
Firing animation uses 33 levels, or 17 for larger sprite sets.
