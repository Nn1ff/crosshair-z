# Crosshair Z 2.0.3

Subtle interface sounds, adapted from the local Crosshair Y samples.

## Changes

- Sound feedback for navigation, selecting a crosshair, buttons, switches and designer adjustments.
- Slightly shifted pitch, a softer high end and short fades for the adapted samples.
- Interface sound toggle, volume and preview under Settings. Preferences persist across app sessions.
- No startup or hover sounds. Rapid adjustments are throttled, and muting stops active sounds immediately.
- Ten bundled mono samples, totaling approximately 195 KB; no additional runtime dependencies.

## Upgrade

Download `Crosshair-Z.exe` or use the in-app updater. Existing settings and saved crosshairs carry over.

## Validation

- 32 JavaScript tests, including sound preference persistence, mute behavior, throttling and sample format.
- Native settings UI, bundled audio decoding and sound controls checked in WebView2.

`SHA256SUMS.txt` contains the SHA-256 checksum of the portable executable.
