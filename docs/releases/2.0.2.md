# Crosshair Z 2.0.2

A simpler interface with layout and control styles adapted from Crosshair Y.

## Changes

- Neutral dark surfaces, consistent crosshair cards and a quieter designer grid, with Z's blue accent.
- Tabs with icons; Share and Import grouped on the right.
- Direct access to Browse and Designer from the start page, plus a Refresh action for discovery picks.
- Shorter transitions and support for reduced motion.
- Keyboard support for equipping crosshairs and switching tabs.

## Upgrade

Download `Crosshair-Z.exe` or use the in-app updater. Existing settings and saved crosshairs carry over.

## Validation

- 27 JavaScript tests, 105 Rust unit tests and the golden sprite comparison passed.
- Native settings UI checked at the default window size and at 1000 × 640.
- Search, designer navigation, keyboard controls and reduced motion checked in the native app.

`SHA256SUMS.txt` contains the SHA-256 checksum of the portable executable.
