## DOM Fortnite rendering correction

- Imported four-arm rectangle crosshairs use Chromium's SVG renderer, matching Crosshair Y's local geometry, Gaussian filters and layer scaling. Other crosshair types retain the existing Canvas renderer.
- Preserve fractional line lengths such as DOM Fortnite's 2.5 instead of rounding during import.
- Render SVG layers at the designer's output resolution so glow stays smooth while zooming, using the same SVG model for actual-size previews and native overlay sprites.
- Wait for SVG decoding before exporting sprites, and invalidate old disk sprites after the rendering change.

Validation: 34 JavaScript tests, including comparison with an independent SVG fixture derived from the shipped Crosshair Y rectangle geometry at 1×, 2×, 8× and 16×. Maximum premultiplied-channel difference is 3/255 (SVG filter rasterization). Existing Canvas presets retain their renderer.

Previously imported profiles must be imported again to recover values that older imports rounded away.
